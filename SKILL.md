# stream-to-shorts

Навык превращает запись стрима в два продукта:

1. **YouTube-версию** — полный стрим с зацензуренным матом (звук глушится в окнах плохих слов) и интро;
2. **вертикальные клипы** 1080×1920, 60 fps, с вжёнными субтитрами — для TikTok / Shorts.

Вызывать навык, когда есть запись стрима (или несколько) и нужен разбор на полную версию
и короткие вертикальные нарезки.

Ниже — рабочий порядок. Порядок важен: каждый следующий шаг опирается на артефакты предыдущего.

---

## 0. Где что лежит

Запись стрима (шаг 0, до этого навыка) делает `recorder/`: CLI + пользовательский таймер
systemd, которые через obs-websocket поднимают OBS и пишут эфир в `STREAMREC_OUTDIR`
(по умолчанию `~/Videos/streams`); канал — только в `~/streamrec/.env` (`STREAMREC_CHANNEL`).
Эта же папка указывается в `stream_root`. Подробности — `recorder/README.md`.

Все пути берутся из `config.json` (см. `config.example.json`; `config.py` читает `config.json`
в корне репозитория или файл из переменной окружения `STS_CONFIG`). Абсолютных путей в этом
документе нет — только ключи конфига и раскладка репозитория.

| Что | Где |
|---|---|
| исходные записи | `stream_root` — по имени запись находит `scripts/sources.py` (`find_source(name)`: корень или подпапка) |
| разбор одного исходника | `<analysis_dir>/<имя>/` (`analysis_dir` по умолчанию `<stream_root>/_analysis`) |
| YouTube-версия | `youtube/` рядом с исходником: интро + полная версия |
| клипы (TT/Shorts) | `clips/` и `clips_vertical/` — рабочие папки нарезки |
| код | `scripts/` в репозитории |
| шаблоны EDL | `examples/edl_youtube.json`, `examples/edl_clip.json` |

Одна игра/один стрим — одна папка. Исходники и промежуточные файлы не смешивать между
разными стримами.

## 1. Анализ (всё на GPU, ориентировочно ~15 мин на 2.5 ч записи)

Выполнять по порядку — каждый шаг читает результат предыдущего:

1. `python scripts/analyze.py <video>` — GigaAM (`v3_ctc`): транскрипт и слова.
   Кладёт в `<analysis_dir>/<имя>/`: `audio.wav`, `words.json`, `transcript.txt`,
   `loudness.json`, `peaks.txt`. Флаг `--force` пересчитывает, `--out-dir DIR` меняет папку.
2. `python scripts/moments/separate.py <name>` → `voice.wav` — отделение голоса
   (`audio-separator` + `vocals_mel_band_roformer`).
3. `python scripts/moments/features.py <name>` → `features.csv` — посекундные признаки:
   arousal/dominance/valence, `emo_*`, смех, крик. `--batch N`, `--device cuda|cpu`.
4. `python scripts/moments/rank.py` — ранжирование моментов по `features.csv` →
   `<out_dir>/moments/candidates.md` и `candidates.json` (`--out-dir` меняет папку,
   `--sources` — список исходников).

Для глушения мата в YouTube-версии отдельно:

```
python scripts/yt_mutes.py <src> --rule letter|tt [--edl <edl.json>] [--report] [--edl-auto]
```

`yt_mutes.py` прогоняет `faster-whisper large-v3` по всему стриму и строит окна мата.

### Два важных технических замечания

- **Окна мата строятся по ВРЕМЕНИ GigaAM.** Слияние GigaAM↔Whisper разъезжается на
  повторах: одно и то же слово, сказанное несколько раз подряд, склеивается в одно длинное
  окно (наблюдали окно ~4.5 с на обычной речи). Поэтому таймингом окна всегда служит GigaAM,
  а не время из слияния.
- **Мат, который услышал только Whisper, берётся по времени слияния**, и слова длиннее
  `> 1.2 с` при этом отбрасываются — иначе в окно попадает лишняя речь.

Матерные слова ищутся в GigaAM **ИЛИ** в Whisper (объединение), а не в одном источнике:
пропуск хотя бы одного вхождения = утечка мата в публикацию.

## 2. YouTube-версия (полная запись)

### Что вырезаем

Вырезать **только**:

- тишину;
- технические разборки (настройка OBS / вебки на экране, «сейчас поправлю»);
- хвост после «пока» (заставка offline);
- всё, что пользователь назвал личным/приватным. Спорные фрагменты — собрать таблицей
  (таймкод + что там) и отдать на утверждение, а не резать молча.

Всё остальное остаётся. Не «улучшать» стрим по своему вкусу.

### Цензура мата

Правило (ключи `censor` в конфиге):

- окно глушения — **40 % длины слова** (`window_frac: 0.40`), минимум **0.15 с**
  (`min_window_sec`); окно центрируется по середине слова и обрезается по его границам;
- **худшее слово** (совпадение по целому слову) глушится **целиком**, плюс `word_pad_sec`
  (0.03 с) с каждой стороны;
- матерное слово ищется в GigaAM **ИЛИ** в Whisper.

Ложные срабатывания (обычное слово, внутри которого оказался корень мата) выносятся
в `okwords.txt` — только с согласия пользователя, не самовольно.

### Интро

Интро — 4.5 с, рисуется процедурно в стиле игры
(`python scripts/intro/undertale_style.py --title TEXT --out FILE`), громкость **−6 дБ**.

### Сборка и приёмка

```
python scripts/youtube/build.py --edl <edl.json>     # ffmpeg, NVENC (h264_nvenc)
python scripts/youtube/verify.py --edl <edl.json>    # приёмка
```

`build.py` накладывает цензуру по таймкоду исходника, склеивает оставшиеся сегменты и
добавляет интро. Безопасные режимы: `--dry-run`, `--test`, `--smoke`.

`verify.py` проверяет геометрию/кадровую частоту/SAR/длительность, синхронность A/V и
окна цензуры. **Приёмка обязательна** — публиковать без зелёного `verify.py` нельзя.

**Пики −52…−58 дБ в коротких окнах — это норма.** Так размазывается AAC на границах
вырезанных окон; средний уровень при этом −85…−90 дБ. Не гоняться за этими пиками и
не «дочищать» их повторным рендером.

**Главы в описании** пересчитать из времени исходника в выходное: прибавить интро и
вычесть все вырезанные куски.

## 3. Клипы (Shorts / TikTok)

### Отбор

- Прочитать **транскрипт целиком** и отдельно посмотреть `rank.py` по `features.csv`.
  Ранжирование подтверждает примерно половину моментов; тихий юмор ловится **только чтением**.
- Готовый список моментов отдать пользователю на утверждение.
- **Не брать**: спорное (азартные игры и т.п.), шутки про нации, всё, что пользователь
  попросил не выкладывать.

### EDL

EDL генерируется скриптом. Поля, которые читает рендер (`scripts/clips/render_tt.py`):
`name`, `src`, `segments`, `punch`, `title`, `caption_y`, `caption_off`, `extra_mute`,
`cam_alt`, `layout`, `game_view`, `game_broll` (полный разбор — в `README.md`, раздел
EDL examples). Крючок (`tighten.py`) задаётся не в EDL, а в `<out>/hooks.json`:
имя файла EDL → `[начало, конец]`.

- **Длина 25–35 с** (максимум ~40). Контекст — 2–3 с, дальше развитие и панч.
- Резать зачитку игровых монологов и повторы.
- **Крючок обязателен у КАЖДОГО клипа** — часть зрителей пролистывает на первой секунде.

### Текст субтитров и аудит мата

```
python scripts/clips/fix_words.py <edl.json> [...] [--force]
```

`fix_words.py` берёт текст из Whisper, а тайминг — из GigaAM, и кладёт
`<name>.words.json` / `.txt`.

**Строгий аудит мата — обязательный шаг.** Каждое плохое слово GigaAM (старт ±0.05 с)
должно иметь соответствующее слово в субтитрах. Иначе утечка: вместо фразы с матом в
субтитрах оказывается обрывок вроде «и 5». Проверять глазами по `.words.txt`, а не
надеяться на скрипт.

### Сборка

```
python scripts/clips/tighten.py [--in <dir>] [--out <dir>]     # динамическая перерезка
python scripts/clips/render_tt.py <edl.json> [--sheet]         # движок рендера
```

- `tighten.py` убирает паузы (склейки), ставит крючок первым. `hooks.json` и `visual.json`
  кладутся в `--out`.
- `render_tt.py` — основной движок: EDL → вертикаль 1080×1920, 60 fps, субтитры, punch-зумы,
  цензура, `loudnorm`.
- Передавать **конкретный файл**, а не маску `*.json` — маска захватит `words.json`.
- Дополнительно: `render_vertical.py` (простой вертикальный рендер по уже нарезанным клипам,
  таблица раскладок, `overlay.png`) и `hf_overlay.py` (опциональный прозрачный слой
  HyperFrames, стиль `"hf"` в EDL).

### Проверки по листам кадров (`--sheet`)

- **Субтитры НЕ поверх текста игры.** Если диалог игры вверху — `caption_y` увести ниже
  (например, 1080).
- Проверить раскладку вебки.
- Если в кадре статичный экран (меню, камин), а человек говорит → поставить
  `game_broll: {t}` из подвижного места той же раскладки.
- **Раскладка может меняться посреди стрима** — на каждую раскладку своя строка LAYOUT и
  своё поле `layout` в EDL.
- Громкость **−14 ±1 LUFS**. Если мимо — править только звук (`volume` + `alimiter`),
  пик ≤ −0.2 dBFS.

## 4. Публикация (общие правила)

- **9 shorts в день** — лимит YouTube 10 загрузок в сутки, один запас оставить.
- Публиковать отложенно, **с шагом ~1.5 ч**; самый сильный клип ставить в часы эфира.
- **Стоп-критерий:** если средний клип за 3 дня < ~800 просмотров — снизить темп до 4–5 в день.
- **Не перезаливать** то, что уже есть на канале: повторы режутся и набирают единицы просмотров.
- **Один момент — один ролик.** Не делать два клипа из одного и того же куска.
- **Закреплённый комментарий**: ссылка на канал/платформу и расписание эфиров.
- «Связанное видео» → полная запись этой игры/стрима.
- **Полную версию стрима публиковать на следующий день** до вечернего эфира.

## 5. Заметки агенту, который исполняет навык

- Требуй от постановщика задачи **диагноз, пути, конкретные строки/файлы, решение и критерий
  числом**. Задание без критерия приёмки — повод уточнить, а не догадываться.
- **Не перезаписывай чужие папки** — даже «просто чтобы проверить». Скрипт, запущенный без
  аргументов, пишет в папку по умолчанию: это уже перезапись. Всегда указывай `--in`/`--out`
  явно и никогда не направляй вывод в существующую чужую папку.
- **Принимай работу своим прогоном**, а не по описанию: открой лист кадров, послушай звук,
  проверь `verify.py`.
- **Фильтры с двумя входами проверяй по КАЖДОЙ ветке.** Если на входе вебка и подложка —
  проверь обе, иначе одна ветка тихо ломается.
- Не трогай исходники и не удаляй промежуточные артефакты, которые не создавал.
- Результат работы — файлы и дословный вывод проверки, а не пересказ процесса.

## 6. Форматы EDL и шаблоны

Шаблоны лежат в `examples/`:

- `examples/edl_youtube.json` — EDL полной YouTube-версии: что вырезать, окна цензуры,
  интро;
- `examples/edl_clip.json` — EDL одного вертикального клипа: `segments`, `punch`,
  `title`, `caption_y`, `layout`, `game_broll`.

Настройки раскладок и цензуры — в `config.example.json` (скопировать в `config.json`):
`layouts` (какие бывают раскладки вебки/игры) и `censor` (`window_frac`, `min_window_sec`,
`word_pad_sec`).

Исходные скрипты по шагам: `scripts/analyze.py`, `scripts/sources.py`,
`scripts/yt_mutes.py`, `scripts/moments/*`, `scripts/youtube/*`, `scripts/clips/*`,
`scripts/intro/*`.
